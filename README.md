# GIS / FTTH Automation

Python project for automating selected **GIS data-processing tasks related to FTTH infrastructure**.

The project demonstrates how Python can be used to analyse spatial data, validate FTTH route geometries and attributes, calculate route lengths and generate technical summaries.

## 🎯 Project goals

The project demonstrates automation of common GIS / FTTH workflows, including:

* processing spatial data,
* analysing fiber-optic routes,
* calculating route lengths,
* validating geometries,
* validating attribute data,
* detecting missing information,
* generating technical summaries,
* exporting processed results.

The project combines practical experience in **GIS and FTTH infrastructure** with Python-based workflow automation.

## 🛠️ Technologies

* **Python**
* **GeoPandas**
* **Shapely**
* **pandas**
* **GeoJSON**
* **EPSG:2180** for metric spatial calculations

## ✅ Implemented functionality

The current version of the project includes:

* loading FTTH route data from GeoJSON,
* FTTH route length calculation,
* reprojection to a metric coordinate reference system,
* geometry validation,
* geometry type validation,
* attribute validation,
* detection of missing data,
* detection of zero-length segments,
* automatic validation status: `OK` / `CHECK`,
* route statistics generation,
* CSV summary export,
* validated GeoJSON export.

## 🗺️ Workflow

The analysis follows these steps:

1. Load sample FTTH spatial data.
2. Validate required attributes.
3. Check route geometries.
4. Reproject data to `EPSG:2180`.
5. Calculate route lengths in metres.
6. Assign validation status to each route.
7. Generate overall statistics.
8. Export analysis results.

No production or customer infrastructure data is used.

## 🔎 Data validation

The script currently checks:

* missing required attributes,
* empty geometries,
* invalid geometries,
* incorrect geometry types,
* zero-length route segments.

Each feature receives a final validation status:

* `OK` – the route passed validation,
* `CHECK` – the route requires review.

## 📤 Output

The program generates two output files.

### `route_summary.csv`

Contains overall analysis statistics, including:

* number of analysed segments,
* total route length,
* average segment length,
* invalid geometry count,
* missing attribute count,
* number of routes requiring review.

### `validated_routes.geojson`

Contains the original FTTH geometries enriched with additional validation information, including:

* calculated route length,
* geometry validation results,
* attribute validation results,
* final validation status.

## ▶️ Running the project

Install the required Python packages:

```bash
python -m pip install -r requirements.txt
```

Run the analysis:

```bash
python src/analyze_routes.py
```

Generated results will be saved in the:

```text
output/
```

directory.
